# Basic Network Services: SSH and Apache Web Server

## Overview

As part of my Ubuntu Server network services lab, I configured and tested two basic network services:

* **SSH** for remote administration
* **Apache2** for hosting a basic web page

The Ubuntu Server is connected to the homelab network at:

```text
Server IP: 10.0.0.10
```

---

## 1. SSH Server

### Installation

I installed the OpenSSH server package on Ubuntu Server:

```bash
sudo apt update
sudo apt install openssh-server
```

### Verify SSH Service

I verified that the SSH service was running:

```bash
sudo systemctl status ssh
```

<img width="673" height="235" alt="image" src="https://github.com/user-attachments/assets/f98b3eaf-a520-4eff-86da-890e3df38b34" />

The service was active and running.

I also checked that the server was listening on TCP port 22:

```bash
sudo ss -tulpn | grep :22
```

## 2. Apache Web Server

### Installation

I installed Apache2 on the Ubuntu Server:

```bash
sudo apt install apache2
```

I then verified that the Apache service was running:

```bash
sudo systemctl status apache2
```

### Web Root

Apache serves website files from:

```text
/var/www/html/
```

The main page is:

```text
/var/www/html/index.html
```

I customized the HTML page to display a message confirming that the Ubuntu Server web server was functioning.

### Testing the Web Server

From another machine on the homelab network, I tested the web server using:

```bash
curl http://10.0.0.10
```

<img width="376" height="35" alt="image" src="https://github.com/user-attachments/assets/524224d0-d421-464e-9368-1807d3bebd12" />

The server successfully returned the HTML response from the Apache web server.

The website could also be accessed through a web browser at:

```text
http://10.0.0.10
```

### Network Service

```text
Service: Apache2 / HTTP
Protocol: TCP
Port: 80
Purpose: Web hosting
Web Root: /var/www/html/
```

## 3. Service Verification from Kali Linux

I used Kali Linux to verify that the services were accessible over the network.

```bash
nmap 10.0.0.10
```

<img width="514" height="162" alt="image" src="https://github.com/user-attachments/assets/0427922e-7dd3-47b9-a038-9833afcb398b" />

The expected open ports were:

```text

80/tcp    HTTP
```

This confirmed that the Ubuntu Server was providing network services that could be discovered and accessed by another machine on the homelab network.

## What I Learned

This lab helped me practice:

* Installing Linux network services
* Managing services with `systemctl`
* Understanding network ports
* Connecting to a remote Linux system using SSH
* Hosting a basic web page with Apache
* Testing services using `curl`
* Verifying exposed services using Nmap
* Understanding the client/server model

The basic service flow is:

```text
Client
  │
  │ Request
  ▼
Ubuntu Server
  │
  ├── SSH → TCP 22
  │
  └── HTTP → TCP 80
```

This provides the foundation for later labs involving firewalls, DNS, network traffic analysis, and security monitoring.
